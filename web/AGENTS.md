# 前端约定

- 遵循根目录开发约定；界面保持简洁侧栏、浅分隔表格与暖黄主操作。
- 不引入 Ant Design；使用既有 React、Umi、Tailwind 和 Radix。
- 页面只调用 `src/services/`，不在组件里手写接口路径或维护第二份业务契约。
- `src/services/generated/` 由后端 OpenAPI 生成，不手改；`src/.umi*` 不提交。
- 页面只展示当前客户的实际事件和已保存历史，不能捏造事件或执行进度。
- 中文注释说明职责；界面用业务语言，不展示 Provider、数据库或处理流等实现术语。
- 前端改动运行 `npm run lint`、`npm run build`；交互验收连接真实本地后端。
- 真实聊天不写入源码、日志、测试期望值或截图。浏览器截图只使用明确标记的合成演示。
